# Redesign inspiration — principles,not copied UI

The cited public-source study is [DIRECTIONS.md](DIRECTIONS.md),dated2026-10-17.
It covers ChatGPT,Claude,Perplexity,Open WebUI,LibreChat,LobeHub,chatbot-ui,
assistant-ui,Vercel AI Elements,prompt-kit,shadcn,Linear,Raycast,Superhuman,
Notion,Bear,Obsidian,Apple Messages,Telegram,VS Code,Cursor and Arc.
Reuse those direct public citations and their stated observation limits.

For this redesign,translate those interpretations into explicit constraints:

- Conversation:one primary composer,clear task context,quiet suggestions that
  invoke existing functionality. No cloud/provider/account features copied.
- Reading:warmth comes from spacing,type and semantic surfaces,not faint text.
  Existing Archivo controls and optional Spectral prose;no proprietary fonts.
- Evidence:source chips must open actual indexed passages,not look like a trust
  seal. No automatic web retrieval or fabricated citation introduced.
- Keyboard:discover real actions;do not list unsupported commands or layouts.
- Panels:hide absent capabilities;do not import an IDE's terminal/extensions.
- Messaging:distinguish roles without decorative avatars or unsupported presence.
- Components:small shared primitives and state contracts;no registry installs,
  snippets or dependency trees solely to imitate a screenshot.

License boundary:public viewing does not permit copying assets/code. No package
from these products is selected or licensed into Sanctum by this study. Open
source is not assumed permissive:each candidate needs a pinned code/asset license
and branding audit before copying. Current implementation reuses existing
registered fonts/MIT-derived tokens and original code/SVG only. THIRD_PARTY_NOTICES
is retained;no additional third-party license is claimed or dependency added.

User research and authenticated comparative product UX testing remain UNVERIFIED.
No "best" or relative usability improvement is inferred from reference pages.
