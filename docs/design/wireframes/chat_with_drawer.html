How does Sanctum ensure local token generation cannot leak requests over the network?
Sanctum enforces process isolation at the operating system level. The inference engine runs as a supervised child process with no internet access (kernel namespaces on Linux, restricted tokens on Windows). All communication with the gateway occurs over local stdio or named pipes. The egress broker fails closed for all non-allowlisted connections.
