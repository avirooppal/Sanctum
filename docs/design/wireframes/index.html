Design Review & Critique Record

Iteration 1 Review (Initial Skeleton Review) Changes Requested
  • Critique 1 (Honest Metrics): Chat interface lacked visible token statistics; users must see exact prompt/completion counts and generation speed or an honest "unknown".
  • Critique 2 (Safety Banner): Computer use interface lacked an immediate, unambiguous global emergency kill switch visible at all times.
  • Critique 3 (Egress Clarity): Cloud provider configuration did not clarify where API keys reside; must state they are in the OS keychain and never on disk.
  • Critique 4 (Argument Binding): Permission dialog was too generic; must display the exact cryptographic hash of the arguments being approved.
Iteration 2 Review (Refinement & Acceptance) Approved for M3 Implementation
  • Resolution 1: Implemented real-time token/speed metric bar on assistant messages in chat_with_drawer.html.
  • Resolution 2: Added top-level red emergency kill banner with persistent hotkey [Ctrl+Shift+Esc] and immediate process pause in computer_use.html.
  • Resolution 3: Explicitly marked cloud providers as opt-in only with OS Keychain integration in providers_privacy.html.
  • Resolution 4: Added cryptographic argument SHA256 binding and Taint-Elevated warning in permission_prompt.html.
  • Resolution 5: Added disk footprint, idle/peak RAM budgets, and idle-unload rules in packs.html.
