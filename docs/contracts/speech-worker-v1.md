# Speech worker v1

Optional runtime configuration: `speech: {python, profile, model_id}`. All fields
are local paths/registry IDs; existing configurations without `speech` remain valid
and return 503 for audio. Only the authenticated gateway launches the worker through
`--engine-child`, which rechecks inherited Linux isolation. Worker independently
requires a loopback-only namespace, seccomp filter and no-new-privileges.

The gateway accepts `POST /v1/audio/transcriptions` as multipart/form-data, at most
8 MiB including framing, and passes raw bytes on stdin (closed after the request).
Arguments: profile path, model ID, Content-Type, generated trace ID. Stdin is bounded;
worker rejects duplicate/unknown fields, multipart nesting, transfer encodings, absent
or multiple files, malformed framing, bad UTF-8 fields, and unsupported PCM WAV.
Filename is informational only and is never opened or used as a storage path.

Fields: file, model, language, prompt, response_format, diarize, optional context JSON.
The solo gateway supplies workspace `solo`, data class `restricted`, cloud disabled.
A legacy context is accepted only for that same workspace/class/cloud setting; trace
is generated by the gateway. This route does not read or persist Knowledge documents.
Model must match the configured ID and registry SHA-256 and ASR capability.

One stdout JSON response: `{ok:true, content_type, result}` or
`{ok:false, status:400|413|422|503, error}`. Diagnostics never contain uploaded audio,
transcripts, local paths or engine stderr. Worker deadline is 150 seconds, ASR at most
120 seconds. Gateway kills/reaps a worker exceeding 160 seconds. No network fetches.

The backend uses explicit `vad.engine=none` whole-file mode or additive `silero.cpp`
profiles with registry/model/binary verification (ADR 0022). Whole-file mode does not
label all audio as detected speech. Both reject diarization without an engine.
VAD has a 20s timeout; the 150s worker deadline covers VAD and all ASR segments.
Only JSON/text/verbose_json/VTT responses are implemented. TTS/realtime stay disabled.
